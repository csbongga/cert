# ระบบออกใบประกาศออนไลน์ (PHP + MySQL)

ผู้อบรมสมัครสมาชิก → เลือกหลักสูตร → ทำแบบทดสอบ → ผ่านเกณฑ์แล้วดาวน์โหลดใบประกาศเป็น **PDF**
ผู้ดูแลระบบเพิ่มหลักสูตร เพิ่มข้อสอบ/ช้อยส์/เฉลย และเลือกภาพเทมเพลตใบประกาศได้

---

## ความต้องการของระบบ
- PHP 7.4 ขึ้นไป (เปิดส่วนขยาย **gd** และ **mbstring**)
- MySQL / MariaDB
- แนะนำใช้ **XAMPP** บน Windows

## การติดตั้ง (ครั้งแรก)

1. **เปิด MySQL และ Apache** จาก XAMPP Control Panel

2. **สร้างฐานข้อมูล** — เปิด phpMyAdmin (http://localhost/phpmyadmin) →
   เมนู **Import** → เลือกไฟล์ `database.sql` → Go
   (จะได้ฐานข้อมูลชื่อ `certdb` พร้อมตารางทั้งหมด)

3. **ติดตั้งไลบรารีสร้าง PDF (mPDF)** — เปิด Command Prompt ในโฟลเดอร์นี้แล้วรัน:
   ```
   php composer.phar install
   ```
   *(ถ้าไม่ติดตั้ง mPDF ระบบยังใช้งานได้ แต่จะเปิดหน้า “พิมพ์/บันทึกเป็น PDF” ผ่านเบราว์เซอร์แทน)*

4. **รันสคริปต์ติดตั้งข้อมูลเริ่มต้น** — เปิดเบราว์เซอร์ไปที่ `setup.php` หนึ่งครั้ง
   จะสร้างบัญชีผู้ดูแล + หลักสูตรตัวอย่าง + ข้อสอบ 10 ข้อ
   > **เสร็จแล้วให้ลบไฟล์ `setup.php` ทิ้ง**

5. เปิดเว็บที่ `index.php`

### บัญชีเริ่มต้น
| บทบาท | อีเมล | รหัสผ่าน |
|---|---|---|
| ผู้ดูแลระบบ | `admin@example.com` | `admin123` |

> เปลี่ยนรหัสผ่านผู้ดูแลทันทีเมื่อใช้งานจริง (แก้ในฐานข้อมูล หรือสมัครใหม่แล้วปรับ role)

---

## วิธีเปิดใช้งาน

**แบบ A — ผ่าน Apache (แนะนำ, ใช้ .htaccess ป้องกันไฟล์ได้)**
คัดลอกโฟลเดอร์นี้ไปไว้ใน `C:\xampp\htdocs\` (แนะนำเปลี่ยนชื่อโฟลเดอร์เป็นภาษาอังกฤษ เช่น `cert`)
แล้วเปิด `http://localhost/cert/`

**แบบ B — เซิร์ฟเวอร์ในตัวของ PHP (ทดสอบเร็ว)**
เปิด Command Prompt ในโฟลเดอร์นี้:
```
php -S localhost:8000
```
แล้วเปิด `http://localhost:8000/`

---

## การตั้งค่า
แก้ไฟล์ [`config.php`](config.php) — ค่าเชื่อมต่อฐานข้อมูล (host, user, pass, ชื่อ DB) และชื่อเว็บไซต์

## โครงสร้างไฟล์
```
config.php            ตั้งค่าฐานข้อมูล/เว็บ
db.php                เชื่อมต่อฐานข้อมูล (PDO)
database.sql          โครงสร้างฐานข้อมูล (import ครั้งเดียว)
setup.php             ติดตั้งข้อมูลเริ่มต้น (ลบทิ้งหลังใช้)
index.php             หน้ารวมหลักสูตร
register / login / logout.php   ระบบสมาชิก
course.php            รายละเอียดหลักสูตร + เริ่มสอบ
quiz.php              ทำแบบทดสอบ + ตรวจ + ออกใบประกาศ
certificate.php       ดาวน์โหลดใบประกาศ PDF (มี ?view=html เพื่อพรีวิว)
dashboard.php         ใบประกาศ/ประวัติของผู้ใช้
admin/                แผงผู้ดูแล: หลักสูตร ข้อสอบ ใบประกาศ
includes/             ส่วนหัว-ท้าย, ฟังก์ชันช่วย
lib/cert.php          เลย์เอาต์ใบประกาศ
uploads/templates/    ภาพเทมเพลตใบประกาศ
assets/style.css      สไตล์
```

## การจัดการหลักสูตร (สำหรับผู้ดูแล)
1. เข้าสู่ระบบด้วยบัญชีผู้ดูแล → เมนู **จัดการระบบ**
2. **จัดการหลักสูตร** → เพิ่มหลักสูตร → กด **แก้ไข** เพื่อ
   - อัปโหลดภาพเทมเพลต (JPG/PNG แนวนอน สัดส่วน A4 เช่น 1522×1076)
   - ตั้งเกณฑ์ผ่าน และจำนวนข้อที่สุ่มมาสอบ
   - ปรับตำแหน่ง/ขนาดของชื่อผู้อบรมและชื่อหลักสูตรบนใบประกาศ (มีพรีวิวสด)
3. กด **จัดการข้อสอบ** → เพิ่มคำถาม ใส่ตัวเลือก และเลือกวงกลมหน้า **ข้อที่เป็นเฉลย**

## หมายเหตุด้านความปลอดภัย (ก่อนใช้งานจริง)
- ลบไฟล์ `setup.php`, `composer.phar`
- ตั้งรหัสผ่าน MySQL และแก้ใน `config.php`
- ตั้ง `DEBUG_MODE` เป็น `0` ใน `config.php`
- เปลี่ยนรหัสผ่านบัญชีผู้ดูแล
